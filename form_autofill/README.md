# Form AutoFill Pro

Hybrid cross-platform form automation built with **Flutter** — Android native apps, Windows desktop/browser (Playwright), and web forms — with shared JSON profiles, OCR, and field mapping.

## Automation Platforms

| Mode | Runtime | Use case |
|------|---------|----------|
| **Android Automation** | Accessibility Service + ML Kit | Native Android form apps |
| **Browser Automation** | Playwright sidecar (Chrome/Edge) | Web forms on Windows/macOS/Linux |
| **Hybrid OCR Automation** | Playwright + OCR + Android fallback | Maximum label detection |
| **Windows Desktop** | Win32/UIA bridge (prepared) | Future native desktop apps |

## Features

- **Modular automation layer** (`lib/automation/` + `automation/playwright/`)
- Dynamic input field detection via Accessibility tree
- Auto-fill text fields and auto-select dropdown/spinner values
- Smooth scroll for long forms with retry logic
- Label detection from UI text + OCR fallback
- Fuzzy label matching (Father Name, Mother Name, Gender, Address, DOB, District, etc.)
- Continues filling after scroll with coordinate-aware mapping
- Hive local storage for profiles
- Accessibility & overlay permission setup screens
- Debug logging panel with real-time automation status

## Architecture

```
lib/
├── automation/                 # Modular hybrid automation layer
│   ├── shared/                 # Adapters, form engine, OCR, retry, scroll
│   ├── android/                # Accessibility bridge (preserved)
│   ├── playwright/             # HTTP client + service manager
│   └── windows/                # Win32/UIA preparation stub
├── core/                       # Constants, legacy re-exports
├── domain/                     # Entities & repository contracts
├── data/                       # Hive + JSON profile import/export
└── presentation/               # UI, platform selector, debug panel

automation/playwright/          # Node.js Playwright sidecar (port 3939)
android/.../kotlin/             # Original Accessibility + ML Kit (unchanged)
```

### Playwright sidecar setup (Browser / Web automation)

```powershell
cd automation/playwright
npm install
npm run install-browsers
npm start
```

Then in the app: select **Browser Automation**, enter form URL, tap **Start**.

## Enable Permissions (Required)

1. Open app → **Settings** tab
2. Tap **Accessibility Service** → Enable **Form AutoFill Pro**
3. Tap **Display Over Other Apps** → Allow overlay (optional, for status)
4. Create or edit a **Profile** with your form data
5. Open the target form app (browser, government app, etc.)
6. Return to Form AutoFill → **Dashboard** → **Start Auto-Fill**

## Release Signing (Production)

1. Generate keystore:

```powershell
keytool -genkey -v -keystore form-autofill-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias formautofill
```

2. Create `android/key.properties`:

```properties
storePassword=YOUR_STORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=formautofill
storeFile=../form-autofill-key.jks
```

3. Update `android/app/build.gradle` signingConfigs (uncomment release signing block).

4. Build:

```powershell
flutter build apk --release
```

## Label Keys Supported

| Key | Matches |
|-----|---------|
| father_name | Father Name, Father's Name |
| mother_name | Mother Name |
| gender | Gender, Sex |
| address | Address, Permanent Address |
| dob | DOB, Date of Birth |
| district | District |
| full_name | Full Name, Applicant Name |
| email, phone, pincode, state, city, aadhaar, pan | Common synonyms |

Add custom synonyms in `lib/core/utils/label_matcher.dart` and `engine/LabelMatcherEngine.kt`.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Auto-fill does not start | Enable Accessibility Service for this app |
| Fields not detected | Scroll manually once; ensure labels are visible |
| Dropdown not selecting | Set exact option text in profile (e.g. "Male") |
| OCR not working | Android 11+ required for screenshots; grant all permissions |
| Build fails | Run `flutter clean && flutter pub get` |
| flutter not found | Add Flutter `bin` to system PATH |
